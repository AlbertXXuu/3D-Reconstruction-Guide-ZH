# 论文与文章阅读目录

这里收录与三维重建相关的中文阅读笔记、方法解释和有证据的复现报告。文章可以先于可运行教程进入指南，但必须说明已经完成到哪一步；只有读过论文，不代表已经搭好环境或验证了模型。

当前尚无独立文章条目。三个现有模型的安装与 Demo 步骤在[模型操作目录](../models/README.md)，实测条件在[验证记录](../validation.md)。后续条目按主题添加到此页，每条写清标题、来源、阅读状态和验证范围，不把待阅读链接放入已支持模型列表。

## 添加一篇文章

复制[文章模板](../templates/article.md)到本目录，例如 `docs/articles/方法简称.md`，保留实际需要的段落，然后在此页添加一行：

```text
文章标题 | 官方论文或项目链接 | 待阅读 / 已阅读 / 已复现 | 本指南文章相对链接 | 验证范围或下一步
```

状态的含义如下：

| 阅读状态 | 需要说明的内容 |
|---|---|
| 待阅读 | 已定位一手来源及发布日期，尚未完成阅读；不要写确定的方法结论。 |
| 已阅读 | 用自己的话说明问题、方法、证据和限制，区分作者结论与个人推断；尚未运行的内容明确标注。 |
| 已复现 | 列出实际复现的部分、源码提交、环境、输入、命令和观察结果；说明是否达到论文的评价条件。 |

优先链接作者或会议的论文页面、官方项目页、官方仓库。记录论文发布日期与本次核查日期；版本不同可能改变结论。阅读笔记使用原创表达与必要的短引用，不上传未经授权的论文 PDF、整篇译文、课程材料或他人的图表。图片和数据另行确认许可与归属。

文章中的实验若具备可重复操作，可再建立[项目条目](../projects/README.md)或[模型操作页](../models/README.md)，并互相链接。个人下载文件、笔记附件与实验产物放在本地资源目录；公开页只保留来源、授权情况与复现所需信息。具体组织方式见[扩展指南](../extending.md)和[贡献指南](../../CONTRIBUTING.md)。
