# 项目与工具目录

这里接收与三维重建有关的数据集、结果查看工具、评测脚本和组合实验。它们不必拥有模型权重，也不必接入网页启动器。每个条目应先说明完成的任务，再说明安装、输入、操作和结果。

当前尚无独立项目或工具条目。DUSt3R、MASt3R、VGGT 的可运行路线仍在[模型操作目录](../models/README.md)，其已验证范围见[验证记录](../validation.md)。不要把一个仅保存了官方链接的新项目写成已验证教程。

## 添加一个项目

复制[项目模板](../templates/project.md)到本目录，例如 `docs/projects/项目简称.md`，在本页增加链接及简短说明。每个条目至少写明官方来源、用途、状态和验证范围：

```text
项目名称 | 数据集 / 工具 / 组合实验 | 官方来源 | 待验证 / 部分验证 / 已验证 | 操作页相对链接
```

| 状态 | 含义 |
|---|---|
| 待验证 | 已确认来源与适用任务，尚未实际执行操作。 |
| 部分验证 | 只完成文中明确列出的步骤，例如下载、CPU 导入或小样本转换；其他步骤仍待验证。 |
| 已验证 | 操作页所声明的范围已经实际运行，并检查了对应结果；不代表覆盖其他机器、全量数据或所有功能。 |

第三方源码使用固定提交或正式发布版本；下载的数据集记录版本、来源和使用许可。工具输出写到本地 `outputs/`，数据、权重和环境不放入公开仓库。若项目需要你的个人数据，公开教程提供有合法来源的样例或输入格式说明，并列出读者需要自行准备的条件。

复用现有能力：纯文档条目无需新增依赖；独立工具先使用自身命令；确实需要统一管理时再接入已有脚本。只有模型 Demo 的完整支持才需要按照[贡献指南](../../CONTRIBUTING.md)修改启动入口与配置。项目组合也应链接现有安装教程，避免维护多份互相冲突的环境命令。

个人实验与公开指南的衔接方式，以及新增内容应放在哪里，见[扩展指南](../extending.md)。
