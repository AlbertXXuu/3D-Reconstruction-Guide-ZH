# 中文实操文档导航

按照“安装 → 一个模型跑通 → 排错 → 核对验证 → 贡献”的顺序阅读。

| 内容 | 入口 | 读完应能完成什么 |
|---|---|---|
| 共用安装 | [Windows 环境配置](windows-setup.md) | 固定源码、三套独立环境、权重校验、本机配置与检查 |
| 模型操作 | [模型目录](models/README.md) | 按样图重建、查看三维场景、下载结果 |
| 故障排查 | [排错手册](troubleshooting.md) | 定位第一处失败，检查解释器、依赖、显存和端口 |
| 依赖定义 | [环境说明](environments/README.md) | 找到可安装的 core 文件，理解固定版本的范围 |
| 验证范围 | [验证记录](validation.md) | 区分实测结果、未验证路线和精度限制 |
| 官方来源 | [来源清单](model-sources.json)、[第三方归属](third-party-notices.md) | 查固定提交、权重校验、补丁和许可 |
| 补充内容 | [贡献指南](../CONTRIBUTING.md) | 增加一份模型教程、问题复现或硬件验证记录 |

共用安装命令集中在安装教程，模型页只保留各自操作。新增模型先在 `docs/models/<model>.md` 写出一条可验证流程，更新此处与模型目录的链接；未运行的内容明确标注，不把计划写成已支持。
